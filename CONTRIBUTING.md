
# Como contribuir

1. Abra uma Issue descrevendo a melhoria ou correção.
2. Crie uma branch a partir de `develop` (`feat/`, `fix/` ou `docs/`).
3. Mantenha o código simples, organizado e legível.
4. Execute os testes (`npm test` no backend e `npm run build` no frontend).
5. Abra um Pull Request para `develop`. A `main` recebe apenas versões estáveis.
